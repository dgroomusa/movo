# movo — concept prototype

"The AI that knows how you travel." A clickable concept prototype for a personal travel planner, built as a single self-contained HTML file.

- **Prototype:** `movo-prototype.html` (the root `index.html` redirects here)
- **All screens at once:** add `?gallery` to the URL; `?gallery&dark` for the dark theme
- **Scope & screen inventory:** `movo-scope.md`
- **Design system notes:** `movo-design-system.html`
- **Screen exports (2x PNG):** `exports/`
- **Local preview:** `python3 serve.py` then open http://localhost:8765/

The Figma source lives in the `ux-growth-project_work` file; `movo-figma-state.json` records the token and frame IDs used to keep it in sync.
